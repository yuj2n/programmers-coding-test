# [Programmers] 게임 맵 최단거리 (Level 2)

핵심 키워드: `#BFS` `#Queue` `#Shortest_Path` `#Matrix_Navigation` `#Java`

---

## 1. 문제 설명

주어진 $N \times M$ 크기의 게임 맵에서 출발지(좌측 상단)로부터 목적지(우측 하단 상대 팀 진영)까지 벽을 피해 도달할 수 있는 **최단 거리**를 구하는 문제.

- **이동 방식**: 상, 하, 좌, 우 4방향으로만 이동 가능. (0은 벽, 1은 갈 수 있는 길)
- **핵심 포인트**: 최단 거리를 구하는 문제이므로, 깊게 파고드는 DFS(깊이 우선 탐색)가 아닌 물 퍼지듯 사방으로 퍼져나가는 BFS(너비 우선 탐색)를 사용해야 효율성 테스트를 통과할 수 있음.

---

## 2. 풀이 방식 (Java / BFS 활용)

2차원 격자 지도를 탐색하기 위해 방향 벡터(Direction Vector)와 **Queue**를 사용하며, 방문 여부와 거리를 동시에 기록하는 `distances` 배열을 활용해 공간 복잡도를 최적화하여 해결.

### 💡 로직 설명

1. **2차원 배열 크기 정의**: `maps.length`를 통해 세로(ROW) 길이를, `maps[0].length`를 통해 가로(COL) 길이를 정확히 파악합니다.
2. **거리 배열 초기화**: 방문하지 않은 칸을 구별하기 위해 전체 `distances` 배열을 `-1`로 채운 뒤, 시작점 `(0, 0)`의 거리를 `1`로 설정합니다.
3. **방향 벡터 설정**: 상, 하, 좌, 우 이동 시 좌표 변화량을 담은 `dr`, `dc` 배열을 생성하여 4방향 탐색을 자동화합니다.
4. **큐를 통한 탐색**: `queue.poll()`을 통해 현재 조사할 위치(`current`)를 꺼내고, 사방을 조사하여 '아직 방문하지 않은 길'이 있다면 이전 거리 + 1 값을 맥이고 큐에 추가합니다.
5. **결과 반환**: 목적지 `(ROW-1, COL-1)`에 처음 도달하는 순간의 거리를 즉시 반환하며, 큐가 빌 때까지 도달하지 못하면 `-1`을 반환합니다.

## 3. 시행착오 및 핵심 개념 정리

### DFS(깊이 우선 탐색)의 한계

- DFS는 한 방향으로 끝까지 파고드는 성질이 있어, 처음 목적지에 도달하더라도 그것이 **최단 경로라는 보장이 없음**.
- 최단 경로를 검증하려면 미로 안의 모든 경우의 수를 다 탐색해야 하므로 맵이 커질 경우 **시간 초과**가 발생함. 따라서 최단 거리는 무조건 **선입선출(FIFO)** 구조의 큐를 쓰는 **BFS**가 정답임.

### 2차원 배열의 ROW(세로)와 COL(가로) 구조 파악

- `maps.length`는 큰 바구니에 담긴 가로줄들의 개수이므로 세로 크기(ROW)가 됨.
- `maps[0].length`는 첫 번째 가로줄 하나 안에 들어있는 칸수이므로 가로 크기(COL)가 됨.
- 좌표 평면을 다룰 때는 `maps[r][c]` 형태로 접근하며, `r`은 세로(위아래) 위치를, `c`는 가로(좌우) 위치를 통제함.

### 방향 벡터 `dr`, `dc` 배열의 원리

- `dr = {-1, 1, 0, 0}`과 `dc = {0, 0, -1, 1}`은 같은 인덱스끼리 짝을 이루어 작동함.
- `i = 0`일 때 `(-1, 0)`은 세로만 위로 한 칸 가므로 '상'을 의미하고, `i = 1`일 때 `(1, 0)`은 **'하'**, `i = 2`일 때 `(0, -1)`은 **'좌'**, `i = 3`일 때 `(0, 1)`은 '우'를 뜻함. 사방으로 분기문을 따로 적지 않고 `for`문 하나로 처리할 수 있는 핵심 스킬임.

### Java 문법 주의점

- **배열 데이터 선언**: JavaScript와 달리 Java에서 배열의 실제 데이터를 중괄호가 아닌 대괄호(`int[] dc = [0, 0, -1, 1]`)로 쓰면 컴파일 에러가 발생함. Java 배열 값은 반드시 중괄호 `{}`로 감싸야 함.
- **`poll()`과 `remove()**`: 둘 다 큐의 선두 데이터를 반환하고 삭제하지만, 큐가 비어있을 때 `remove()`는 에러를 던지고 `poll()`은 `null`을 반환하므로 코딩 테스트에서는 `poll()`이 더 안전함.
