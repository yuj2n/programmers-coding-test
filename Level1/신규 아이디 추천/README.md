# [Programmers] 신규 아이디 추천 (Level 1)

## 1. 문제 설명

카카오에 입사한 신입 개발자 네오가 설계한 **7단계의 아이디 거르기 규칙**을 구현하는 문제입니다. 입력된 `new_id`가 규칙에 맞지 않을 경우, 유사하면서도 규칙에 맞는 새로운 아이디를 추천해 주는 로직을 작성해야 합니다.

---

## 2. 풀이 방식 (문자열 처리 & 정규표현식)

이 문제는 각 단계의 요구사항을 **순차적으로** 적용하는 것이 핵심입니다. 자바스크립트의 문자열 메서드와 **정규표현식(Regular Expression)**을 활용하면 복잡한 필터링 조건을 간결하게 처리할 수 있습니다.

### 💡 로직 설명 (7단계 프로세스)

1.  **소문자화**: `toLowerCase()`를 이용해 모든 대문자를 소문자로 바꿉니다.
2.  **문자 제거**: 정규표현식 `/[^a-z0-9-_\.]/g`를 사용하여 알파벳 소문자, 숫자, 빼기(-), 밑줄(\_), 마침표(.)를 제외한 모든 문자를 제거합니다.
3.  **마침표 통합**: `/\.{2,}/g`를 사용하여 연속된 마침표(..)를 하나의 마침표(.)로 치환합니다.
4.  **양 끝 마침표 제거**: `/^\.|\.$/g`를 사용하여 문자열의 시작과 끝에 위치한 마침표를 제거합니다.
5.  **빈 문자열 처리**: 결과가 빈 문자열이라면 "a"를 대입합니다.
6.  **길이 제한**: 길이가 16자 이상이면 앞의 15자만 남기고, 잘린 후 끝에 위치한 마침표를 다시 제거합니다.
7.  **최소 길이 충족**: 길이가 2자 이하라면, 마지막 문자를 길이가 3이 될 때까지 반복해서 붙입니다.

---

## 3. 핵심 포인트

### ✅ 정규표현식의 효율성

반복문으로 모든 문자를 검사하는 대신, 정규표현식을 사용하면 복잡한 패턴 매칭을 단 한 줄로 해결할 수 있습니다.

- `[^...]`: 대괄호 안의 문자들을 제외한 나머지.
- `\.{2,}`: 마침표가 2번 이상 반복됨.
- `^`와 `$`: 각각 문자열의 시작과 끝을 의미.

### ✅ 6단계 잘라내기 후 재검사

문자열을 `slice(0, 15)`로 잘랐을 때, 원래는 중간에 있던 마침표가 **새로운 끝 지점**이 될 수 있습니다. 따라서 4단계에서 이미 마침표를 제거했더라도, 6단계 이후에 다시 한번 끝 지점의 마침표(`\.$`)를 검사해 주는 것이 이 문제의 가장 큰 함정입니다.

### ✅ 메서드 체이닝 (Method Chaining)

자바스크립트의 문자열 메서드는 새로운 문자열을 반환하므로, 각 단계를 점(`.`)으로 연결하여 가독성 높은 코드를 작성할 수 있습니다.

---

## 4. 최종 코드 예시

```javascript
function solution(new_id) {
  const answer = new_id
    .toLowerCase() // 1단계
    .replace(/[^\w-.]/g, "") // 2단계
    .replace(/\.{2,}/g, ".") // 3단계
    .replace(/^\.|\.$/g, "") // 4단계
    .replace(/^$/, "a") // 5단계
    .slice(0, 15)
    .replace(/\.$/g, ""); // 6단계

  const len = answer.length;
  return len <= 2 ? answer + answer[len - 1].repeat(3 - len) : answer; // 7단계
}
```

---

### 🚀 성능 분석

- **시간 복잡도**: $O(L)$ ($L$: `new_id`의 길이, 최대 1,000)
  - 각 단계는 문자열을 한 번 혹은 상수의 횟수만큼 순회하며 정규식을 적용하므로 매우 빠르게 동작합니다.
- **공간 복잡도**: $O(L)$
  - 가공된 문자열을 저장할 공간이 필요합니다.
